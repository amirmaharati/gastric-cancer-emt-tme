# Data

This directory contains **small metadata files only**. Large raw datasets, downloaded reference resources, and generated analysis objects are intentionally excluded from version control and are downloaded or generated by the analysis scripts.

## Data sources

| Resource | Purpose | Accession / version | Local location | Obtained by |
|---|---|---|---|---|
| Gastric cancer scRNA-seq | Primary single-cell dataset | **GSE183904** | `data/GSE183904_RAW/` | `R/01_download_qc_integration.R` |
| Sample metadata | Sample-level clinical and tissue annotations | Supplementary metadata for GSE183904 | `data/metadata/Supp.csv` | Included locally / supplied with the project |
| NicheNet prior models | Ligand–receptor, ligand–target, signaling, and TF prior models | NicheNet v2 resources | `data/nichenet/` | `R/06_nichenet_ligand_analysis.R` |
| GENCODE lncRNA annotation | Identification of long non-coding RNAs | **GENCODE release 49** | `data/gencode/` | `R/07_emt_lncrna_analysis.R` |
| TCGA stomach adenocarcinoma | Bulk RNA-seq and clinical survival validation | **TCGA-STAD** | `data/TCGA_STAD/` | `R/08_tcga_stad_survival.R` |

## Directory structure

After the relevant scripts are run, the `data/` directory may look like:

```text
data/
├── README.md
├── metadata/
│   └── Supp.csv
│
├── GSE183904_RAW/          # generated/downloaded; gitignored
├── GSE183904_RAW.tar       # downloaded; gitignored
├── nichenet/               # downloaded; gitignored
├── gencode/                # downloaded; gitignored
└── TCGA_STAD/              # downloaded; gitignored
```

Only lightweight metadata and documentation should be committed to the repository. Raw sequencing data, reference databases, TCGA downloads, and large generated objects are excluded by `.gitignore`.

## 1. GSE183904 single-cell RNA-seq data

The primary dataset is:

**GEO accession: `GSE183904`**

The preprocessing script downloads the GEO raw archive automatically:

```text
R/01_download_qc_integration.R
```

The script:

1. downloads the GSE183904 raw archive;
2. extracts the sample count matrices;
3. creates a combined Seurat object;
4. calculates QC metrics;
5. applies cell-level QC filters;
6. performs sample-wise DoubletFinder analysis;
7. removes predicted doublets;
8. merges retained singlets;
9. performs normalization, variable-feature selection, scaling, PCA, Harmony integration, UMAP, and clustering.

The downloaded files are stored under:

```text
data/GSE183904_RAW/
```

and are **not tracked by Git**.

### QC thresholds used

The current pipeline applies:

```text
nFeature_RNA > 300
nCount_RNA   > 1,000
nCount_RNA   < 50,000
percent.mt   < 30
percent.ribo < 45
percent.hb   < 1
```

The expected doublet-rate parameter used by the reconstructed DoubletFinder workflow is defined explicitly near the top of `R/01_download_qc_integration.R`. If the original experiment-specific loading rate is recovered, that value should be updated before a final reproducibility run.

## 2. Sample metadata

Sample-level annotations are stored in:

```text
data/metadata/Supp.csv
```

This file is used by:

```text
R/02_add_sample_metadata.R
```

The script identifies sequenced samples from rows with a valid `Sample ID`, matches those identifiers to the Seurat object, and transfers available sample-level annotations to each cell.

Key metadata fields include, where available:

- patient identifier;
- sample identifier;
- tissue type;
- Normal / Tumor / Metastasis status;
- age;
- sex;
- tumor location;
- clinical stage;
- Lauren histologic subtype;
- intestinal metaplasia status;
- mismatch-repair information;
- EBV status;
- TCGA molecular subtype.

The cleaned metadata-enhanced Seurat object is generated under `objects/`, which is intentionally gitignored.

### Redistribution note

Before publishing this repository, confirm that redistribution of `Supp.csv` is consistent with the terms of the original supplementary data source. If redistribution is not appropriate, remove the file from the public repository and document how users can obtain it from the source publication instead.

## 3. NicheNet prior models

The NicheNet analysis is performed by:

```text
R/06_nichenet_ligand_analysis.R
```

Required prior models are downloaded automatically into:

```text
data/nichenet/
```

The workflow uses human NicheNet resources for:

- ligand–receptor interactions;
- ligand–target regulatory potential;
- weighted signaling and gene-regulatory networks;
- ligand-to-transcription-factor relationships.

These files can be large and are therefore excluded from Git.

The analysis is designed as a sender-focused:

```text
T/NK cells
    ↓
EMT-low epithelial cells
```

interaction analysis.

## 4. GENCODE long non-coding RNA annotation

The lncRNA analysis uses:

**GENCODE human release 49**

and is performed by:

```text
R/07_emt_lncrna_analysis.R
```

The script downloads the GENCODE release 49 long-noncoding-RNA GTF into:

```text
data/gencode/
```

and uses the annotation to identify lncRNAs present in the GSE183904 epithelial-cell expression matrix.

The downloaded `.gtf` and `.gtf.gz` files are excluded from Git.

## 5. TCGA-STAD validation data

Independent bulk-tumor validation is performed using:

**The Cancer Genome Atlas — Stomach Adenocarcinoma (`TCGA-STAD`)**

The analysis is implemented in:

```text
R/08_tcga_stad_survival.R
```

The script obtains:

- Primary Tumor RNA-seq STAR count data;
- clinical metadata;
- overall-survival information.

Downloaded TCGA files are cached under:

```text
data/TCGA_STAD/
```

and are excluded from Git.

The current survival workflow uses:

```text
raw STAR counts
    ↓
DESeq2 variance-stabilizing transformation
    ↓
candidate lncRNA expression
    ↓
z-standardization
    ↓
univariate Cox proportional-hazards analysis
    ↓
Benjamini–Hochberg correction
```

Overall survival is the primary endpoint.

Any multigene TCGA-STAD risk model generated by the script should be interpreted as **exploratory**, because model fitting and evaluation occur in the same cohort.

## Reproducing the data preparation

Run the analysis from the **repository root**, not from inside the `R/` directory.

The expected order is:

```r
source("R/01_download_qc_integration.R")
source("R/02_add_sample_metadata.R")
source("R/03_cell_type_annotation.R")
source("R/04_emt_scoring.R")
source("R/05_emt_trajectory_monocle3.R")
source("R/06_nichenet_ligand_analysis.R")
source("R/07_emt_lncrna_analysis.R")
source("R/08_tcga_stad_survival.R")
source("R/09_generate_results_summary.R")
```

Each script writes its important outputs to one or more of:

```text
objects/
results/figures/
results/tables/
results/summary/
```

## Provenance

This repository contains a **reanalysis of GSE183904** focused on epithelial–mesenchymal transition, tumor-microenvironment signaling, lncRNA prioritization, and TCGA-STAD survival validation.

It should not be interpreted as a complete reproduction of every analysis performed in the original GSE183904 publication.
